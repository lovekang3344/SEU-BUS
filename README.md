# 东南大学校园接驳车实时查询系统

这是一个为东南大学师生设计的校园接驳车时刻查询系统，帮助大家方便快捷地查询校内各条接驳车线路的发车时间，提升出行效率。（基于2025年10月20日起执行的最新时刻表）

支持 **Web 网页端** 和 **Windows 桌面桌宠** 两种使用方式。

---

## 功能特色

### 🕒 实时班车查询
- 根据当前时间智能显示接下来的班车信息
- 实时计算并显示距离发车时间（等待时间）
- 支持工作日和节假日不同的时刻表
- 默认上车地点为橘园，终点为无线谷

### 🔍 反向查询功能
- 可根据目的地查询所有开往该地点的班车
- 显示从不同站点出发的时间信息
- 便于规划到达特定地点的最佳乘车方案

### 📅 完整时刻表浏览
- 提供所有线路的完整时刻表
- 支持按站点筛选查看
- 可同时查看工作日和节假日时刻表

### 📱 手机端提醒功能
- 支持手机端设置班车提醒
- 声音提醒：使用Web Audio API播放提示音
- 震动提醒：使用Vibration API实现手机震动
- 弹窗提醒：显示详细的班车信息
- 提醒倒计时：实时显示距离提醒触发的时间

### 💻 PC端提醒功能
- 通过浏览器通知功能提醒用户班车即将发车
- 可自定义提醒时间（1-15分钟）
- 支持设置和取消提醒

### 🐿️ 桌面桌宠（Electron）
- 可爱的六朝松鼠角色悬浮在桌面
- 鼠标悬停显示下一班车的到站时间
- 点击展开详情面板，查看后续班次和设置
- 支持设置上车地点、下车地点和提前提醒时间
- 闹钟触发时松鼠抖动 + 红色提示 + 提示音
- 可拖拽移动窗口位置
- 最小化到系统托盘，不占用任务栏
- 无需联网，所有数据本地运行

### 🤖 自动日期检测
- 自动识别周末为节假日模式
- 支持手动切换工作日/节假日

### 📱 响应式设计
- 完美适配手机、平板和电脑等不同设备
- 移动端友好的界面布局
- 触控友好的交互设计

### 🎨 现代化界面
- 使用Vue 3框架构建
- 使用TailwindCSS进行样式设计
- 简洁清新的用户界面设计
- 直观的信息展示方式
- 便捷的操作流程

## 快速开始

### 网页版

直接访问 [GitHub Pages](https://lovekang3344.github.io/SEU-BUS/) 即可使用，无需安装。

### 桌面桌宠版

#### 下载安装
1. 前往 [GitHub Releases](https://github.com/lovekang3344/SEU-BUS/releases) 下载最新的 `.exe` 安装包
2. 运行安装程序，选择安装位置
3. 安装后桌面上会出现"东南大学接驳车桌宠"快捷方式

#### 首次使用
1. 启动桌宠，松鼠会出现在屏幕右下角
2. 鼠标悬停查看下一班车信息
3. 点击松鼠展开详情面板
4. 点击右上角设置图标，配置上车地点和下车地点
5. 设置提醒分钟数，选择下一班车设置闹钟

## 技术栈

- **前端框架**：Vue 3 (Composition API)
- **构建工具**：Vite
- **样式框架**：TailwindCSS
- **桌面端**：Electron 43
- **打包工具**：electron-builder (NSIS)
- **Web API**：
  - Web Audio API（声音提醒）
  - Vibration API（震动提醒）
  - Notification API（PC端通知）

---

## 技术特点

- 现代化前端架构，使用Vue 3 Composition API
- 响应式设计，完美适配各种设备
- 组件化开发，代码结构清晰
- 使用TailwindCSS实现高效样式开发
- 纯前端实现，无需后端服务器
- 零外部依赖，所有逻辑本地运行
- 支持工作日/节假日自动切换
- 数据存储在JSON文件中，便于维护更新
- Electron 桌宠模式：透明窗口、拖拽、系统托盘、持久化配置

## 本地开发

```bash
# 安装依赖
pnpm install

# 网页开发模式
pnpm dev

# 桌宠开发模式（需要同时运行 Vite 服务）
pnpm electron:dev

# 构建网页版
pnpm build

# 打包桌宠安装程序
pnpm dist
```

## 发布流程（给开发者）

### 发布网页版（GitHub Pages）
推送代码到 `main` 分支后，`.github/workflows/main.yml` 会自动部署到 GitHub Pages。

### 发布桌宠安装包（GitHub Release）
```bash
# 1. 确保本地代码是最新的
git pull origin main

# 2. 创建新版本标签（每次发版递增版本号）
git tag v1.1.1
git push origin v1.1.1

# 3. GitHub Actions 会自动在 Windows 服务器构建安装包并创建 Release
# 4. 前往 https://github.com/lovekang3344/SEU-BUS/releases 下载 .exe
```

> **说明**：仓库保持公开（代码可查），Release 里只提供 `.exe` 安装包供用户使用。GitHub 会自动为每个 tag 生成源码压缩包，普通用户无需关心。
